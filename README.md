# PrimerParcial

Parte práctica del primer parcial de la materia Desarrollo de videojuegos
Consiste en crear una esfera donde el material tenga una textura con mi nombre(tanto basemap como normalmap).
Junto a la esfera también hay un spotlight.
Para esta práctica se utilizó Unity 6000.6.3f1

Cada etapa de la práctica quedó registrado en un commit siendo estos: 
!. Creación de la esfera.
2. Texturizando la esfera.
3. Agregar el Spotlight.
4. Cambiar el color de la esfera a rojo.

# Cómo abrir el proyecto
1. Instala Unity 6000.6.3f1.
2. Clona el repositorio.
3. En Unity Hub pulsa Add y selecciona la carpeta dodne clonaste el repositorio.
4. Abre la escena Assets/Scenes/SampleScene.unity
